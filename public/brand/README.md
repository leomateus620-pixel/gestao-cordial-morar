# Identificação das plataformas

Os arquivos são cópias sem alteração dos símbolos servidos pelas próprias marcas:

- `google-ads.svg`: [Google Ads](https://www.gstatic.com/images/branding/productlogos/ads/v5/192px.svg), referenciado na página [Google Ads](https://ads.google.com/home/).
- `meta.svg`: [Meta](https://static.xx.fbcdn.net/rsrc.php/yf/r/-7pQO6hUGK_.svg), referenciado no [Centro de recursos da marca Meta](https://www.meta.com/brand/resources/meta/company-brand/).

Os símbolos identificam as plataformas ao lado de seus nomes; não indicam patrocínio ou parceria. Consulte as regras de marca dos respectivos titulares antes de reutilizá-los em outros contextos.
