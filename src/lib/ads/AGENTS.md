- Marketing ad connectors live in src/lib/ads (pure link parser + per-platform providers implementing AdProvider); missing secrets surface as `not_configured`, never fake values — why: keeps manual campaigns working without credentials.
- Ads sync: cron `meta-ads-sync` every 10 min calls the stable project--…lovable.app /api/public/hooks/ads-sync with the app_settings `worker_hook_token` apikey (the vault value behind internal_worker_headers() is rejected by this hook and the custom domain returned 401); the worker runs ≤8 single-lease jobs per call, refreshes active campaigns each cycle and paused ones every 6 h, and refuses to commit when the provider omits days already stored with spend/impressions (`partial_data`) — why: frequent refresh must never erase or misreport stored metrics.
- Meta Graph fetches use `redirect: "manual"` plus an explicit 3xx rejection, never `redirect: "error"` — why: workerd throws on "error", so every published Meta call failed instantly.
- Google Ads sync runs through the same durable worker as Meta (Explorer access, no developer-token header); Google omits zero days, so a stored day with spend/impressions/conversions missing from a response is always partial_data, never deleted — why: keeps Google series auditable without erasing stored numbers.
